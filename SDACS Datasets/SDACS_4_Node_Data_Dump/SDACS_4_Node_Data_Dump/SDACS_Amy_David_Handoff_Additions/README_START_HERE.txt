SDACS Amy/David Handoff Additions

This package adds missing helper files for two workflows:

1. Amy_MATLAB_Handoff
   Clean MATLAB summary, node position template, and plotting/readme guidance.

2. David_EdgeImpulse_Handoff
   Clean Edge Impulse training CSV, metadata manifest, feature dictionary, label balance, and known issues.

These files are generated from Amy_MATLAB_4_Node_Data_Dump.zip. They do not replace the original data; they make the original data easier to interpret and safer to import.
